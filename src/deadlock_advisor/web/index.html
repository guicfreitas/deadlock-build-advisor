  2. 2Ativar o log do jogo

    É assim que o app sabe quando uma partida começa. Nada é injetado no jogo.

    1. Na Steam, clique com o botão direito em Deadlock → Propriedades…
    2. Em Geral → Opções de inicialização, cole: -condebug
    3. Feche a janela de propriedades.
  3. 3Abrir o Deadlock

    Abra o Deadlock pela Steam (se já estava aberto, feche e abra de novo). Este passo se completa sozinho quando o jogo abrir.
